# One Line, One Chill

Entry for [make.fun's "One Line, One Chill" bounty](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488): a single sentence of horror, under 200 characters, meant to frighten a reader in one breath.

> The police found footprints leading from my daughter's window to my bed, and they stopped at my side of the mattress, still wet, in the exact size of my own shoes.

`main.py` writes exactly that one line (163 characters) to
`/output/entry.txt`, after checking the competition gate: one line, one
sentence, 1 to 200 characters, not only whitespace. No network, no input
files, no arguments.

Run it with:

```sh
python3 main.py
```
